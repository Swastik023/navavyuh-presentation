### 🚨 GOOGLE ALGORITHMIC PENALTIES REFERENCE (Why the Founder Must Act)

| Problem / Finding | Google Algorithm System | Algorithmic Penalty & Trigger | Business Loss / Cost |
|---|---|---|---|
| **01. Homepage Overload** | **RankBrain & Helpful Content** | High short-click bounce (pogo-sticking); marks intent as unsatisfied. | Demoted from Page 1 to Page 2. Loses $15k–$30k/mo in tuition. |
| **02. Booking Redirect** | **E-E-A-T & SpamBrain Quality** | Unannounced external checkout jump triggers merchant risk flags. | **60%–70% cart abandonment**. Students fear payment fraud. |
| **03. Mobile Speed (5.4s)** | **Page Experience & Core Web Vitals** | LCP > 2.5s classified as "POOR". Official mobile ranking demotion. | 53% bounce before 3s. Google ranks faster competitors ahead. |
| **04. YouTube Bloat** | **Total Blocking Time & INP** | Main thread locks for 730ms executing unrequested iframe code. | Drag on domain-wide Core Web Vitals score in Search Console. |
| **05. 2-Second Popup** | **Intrusive Interstitials Penalty** | **Official Google Mobile Demotion** for immediate full-screen modal. | Active mobile search ranking suppression on commercial queries. |
| **06. Aerial Yoga Typo** | **Query-to-URL Relevance** | Exact keyword disconnect ("Arial" the font vs "Aerial" yoga). | Competitors with clean slugs take rank #1 for $1,500+ courses. |
| **07. Missing Course Schema** | **Knowledge Graph & Schema Entities** | **Disqualified from Rich Results** & Google Course Carousels. | Competitors get review stars & 35%+ higher CTR; ashram is invisible. |
| **08. Language Widget** | **Multilingual Hreflang System** | Googlebot does not execute JS widgets; 0 foreign pages indexed. | **100% invisible on Google Germany/Spain**. Millions in lost fees. |
| **09. Mobile UI Collisions** | **Mobile-First Usability Guidelines** | Tap targets too close (<48px); triggers Search Console warnings. | Misclicks cause mobile bounce; cuts inquiry submission by 25%. |
| **10. Missing DMARC** | **Safe Browsing & SpamBrain Defense** | Domain vulnerable to spoofed wire transfer invoices (`p=none`). | Gmail/Yahoo blacklist domain to Spam; catastrophic fraud risk. |
