# 🛡️ Founder Q&A Defense: “How Would You Fix It?”

When the founder asks how you would solve a specific issue, **do not give away free code or full technical implementations**. Give the **high-level strategic direction** that highlights your methodology and collaboration with their developer:

| Founder Question | What You Say Verbatim |
|---|---|
| **“How would you solve the cross-domain booking issue?”** | *“I would first make the booking journey consistent and on-brand with the main website so the student never feels they've left the school. I'd want to inspect the existing booking and payment setup with your developer before deciding the exact implementation path.”* |
| **“How would you fix the YouTube performance problem?”** | *“I would implement on-demand loading so the video only loads when the visitor clicks Play rather than during the initial page open, and then measure the before-and-after speed metrics in Search Console.”* |
